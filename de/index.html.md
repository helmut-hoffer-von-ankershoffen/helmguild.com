# helmguild

> Steuern lernen, wenn das Wetter aufzieht. Mentoring für Engineering Leader und die Agenten, die sie deployen. Engineering-Review auf Abruf.

Fähigkeiten wie Programmieren wandern in die Agent-Schicht. Das Urteil, das diese Agenten mentort, die Engineering Leader mentort, die sie deployen, und das reviewt, was sie ausliefern — das wird knapper. Helmguild kultiviert dieses Urteil in einer föderierten Gilde und verteilt es über ein offenes Protokoll, [AMMP](/de/rfc/ammp/).

## Was hier zu lesen ist

- [Blog](/de/blog/) — das *Warum*. Essays über menschliche Aufsicht im Zeitalter der Agenten.
- [Manifest](/de/manifesto/) — das *Was*. Mission, zwei Dienste, elf Tenets, drei Stufen.
- [AMMP RFC](/de/rfc/ammp/) — das *Wie*. Das Wire-Format, das die zwei Dienste teilen.
